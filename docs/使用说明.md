# 使用说明（小爱音箱怎么触发）

本机桥接服务跑起来之后，对小爱音箱说话即可。  
**必须带触发词**，否则仍走原生小爱，不会进本机大模型 / Cursor。

默认触发词：`帮我`、`请`（可在 `.env` 的 `KEYWORDS` 修改）。

---

## 1. 先确认服务在跑

```powershell
cd <项目目录>
.\scripts\service-status.ps1
```

若未运行：

```powershell
.\scripts\service-start.ps1
```

停止：

```powershell
.\scripts\service-stop.ps1
```

---

## 2. 普通问答（默认大模型）

唤醒后，用「帮我 / 请」开头：

- 「小爱同学，**帮我**今天天气怎么样？」
- 「小爱同学，**请问**你是谁？」

---

## 3. 交给 Cursor（编程助手）

小爱对英文 `cursor` 常听不准，**请用中文别名**。

| 你说 | 效果 |
|------|------|
| 小爱同学，**帮我让编程助手说一声你好** | 交给本机 Cursor |
| 小爱同学，**帮我用写代码执行修复登录** | 同上 |
| 小爱同学，**帮我用代码助手……** | 同上 |
| 小爱同学，**帮我用光标……** | 同上 |

也可用：`小C`、`科瑟`、`克瑟`（听写兜底）。

---

## 4. 特征词绑定到某一个对话（推荐）

把「小爱编程」这类**开始词**绑到固定 Cursor 会话：词本身不当问题，只负责切路由。

在 `agents.yaml`：

```yaml
cursor:
  entry_phrases:
    小爱编程: 小爱编程   # 特征词 → 聊天名
  chats:
    小爱编程: agent-xxxxxxxx   # 或用下面 bind 命令写入
```

绑定已有绘画/编程会话（一次即可）：

```powershell
.\.venv\Scripts\python.exe -m mi_ai agents bind cursor 小爱编程 <agent_id>
```

对音箱：

| 你说 | 效果 |
|------|------|
| 小爱同学，**帮我小爱编程** | 只切换到该会话，**不向模型提问** |
| 小爱同学，**帮我小爱编程画一只猫** | 在该会话里执行「画一只猫」 |

也可用旧写法：「帮我用编程助手在登录里执行……」。

未点名聊天时：按 `resume_policy` 续上次或新建。

---

## 5. 持续对话

- 「小爱同学，**开始持续对话**」→ 之后可少说唤醒词（仍建议带触发词）
- 「小爱同学，**结束持续对话**」→ 退出

---

## 6. 试路由（不真正调用，可选）

不确定口令会进谁时，可在电脑上试：

```powershell
.\.venv\Scripts\python.exe -m mi_ai agents route "让编程助手说一声你好"
.\.venv\Scripts\python.exe -m mi_ai agents route "小爱编程"
.\.venv\Scripts\python.exe -m mi_ai agents route "小爱编程画一只猫"
.\.venv\Scripts\python.exe -m mi_ai agents list
```

---

## 注意

1. 必须先「小爱同学」唤醒，再带 **帮我 / 请**。  
2. Cursor 跑完后音箱只播**短摘要**；完整过程在电脑 Cursor / 日志里看。  
3. 云端 Cursor 默认关闭；要开需改 `agents.yaml` 里 `cursor-cloud.enabled`。  
4. 登录失效时：`python -m mi_ai.login_mina`，完成验证后再 `service-start`。
